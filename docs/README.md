This project uses Vite **8.0.13** (`web/package.json`). Re-download after major Vite upgrades:

```bash
curl -fsSL https://vite.dev/llms-full.txt -o docs/vite-llms-full.txt
curl -fsSL https://vite.dev/llms.txt -o docs/vite-llms.txt
```
