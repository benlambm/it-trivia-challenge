# Vite reference docs (for agents & humans)

Official Vite LLM-oriented documentation, saved locally for offline / in-repo context.

| File | Source | Use |
|------|--------|-----|
| [vite-llms.txt](./vite-llms.txt) | [vite.dev/llms.txt](https://vite.dev/llms.txt) | Compact index and table of contents |

| — | [npmjs.com/package/vite](https://www.npmjs.com/package/vite) | Published package versions |

This project uses Vite **8.0.13** (`web/package.json`). Re-download after major Vite upgrades:

```bash
curl -fsSL https://vite.dev/llms.txt -o docs/vite-llms.txt
```
